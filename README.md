# 2026 AP Psych CED

A concise, searchable local-first study wiki aligned to the 2026 AP Psychology Course and Exam Description.

The site includes separate Unit 0-5 pages, CED Essential Knowledge, concept definitions and examples, topic and unit mind maps, comparison tables, images, and four-choice beginner self-checks.

## GitHub Pages

The repository root is the static site root. GitHub Pages should publish from the `main` branch and `/ (root)` directory.

## Source-material policy

The public repository does not include the full CED or commercial textbook PDFs, OCR outputs, or local build caches. Page references remain visible in the hosted site, while local PDF links continue to work in the local copy. Some small textbook figures are reproduced in an educational study context and are labeled by source; open-license web figures retain creator and license attribution.

This is an independent study aid and is not an official College Board, Barron's, Myers, 5 Steps, or Princeton Review publication.
